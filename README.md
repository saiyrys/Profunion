# Profunion — Backend API

Данный проект является курсовой работой по создании backend-системы для управления мероприятиями, пользователями и новостями на сайте профсоюзной организации ГБПОУ "КСТ" `https://prof-kst-souz.ru`. Backend был создан на `ASP.NET Core`, использует `Entity Framework Core`, `JWT`. Backend разрабатывался с соблюдением архитектурных принципов `SOLID`, `Clean Architecture`, и построен на монолитно модульной архитектуре по принципу `DDD`. В качестве основной базы данных использовалась `MySQL`.

## 🧩 Технологии используемые в реализации проекта

- ASP.NET Core
- Entity Framework Core
- MySQL
- JWT авторизация
- CI/CD (VPS сервер + nginx + SSL)

## ⚙️ Основной функционал backend`a

- Авторизация в системе при помощи JWT.
- Работа с мероприятиями
- Бронирование мероприятий колледжа
- Панель администратора для управления (Пользователями, мероприятиями, новостями,а так же свободными местами на мероприятиях)
- Авторизация по ролям
- Новости

## 🛠️ Архитектура

- `API` — контроллеры и роуты
- `Application` — интерфейсы
- `Domain` — бизнес-логика
- `Infrastructure` — доступ к БД
- `Shared` - Общий контент для сервисов.

## 📦 Развёртывание
